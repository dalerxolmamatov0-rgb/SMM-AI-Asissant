# AI SMM ASSISTANT — TEXNIK TOPSHIRIQ (TZ / TECHNICAL SPECIFICATION)

---

## 1. LOYIHA HAQIDA UMUMIY MA'LUMOT

- **Loyiha nomi:** AI SMM Assistant (Instagram Content & Creative Strategy Platform)
- **Maqsadi:** SMM mutaxassislari, kichik va o'rta biznes egalari, frilanserlar va blogerlar uchun Instagram sahifalariga moslashtirilgan **7 kunlik professional kontent-reja**, to'liq post matnlari (kopirayting), virusli Reels ssenariylari, Stories ketma-ketliklari va kreativ marketing g'oyalarini AI yordamida bir necha soniyada yaratib beruvchi veb-platforma.
- **Tillar:** O'zbek tili (Lotin/Kirill), Rus tili, Ingliz tili.
- **Platforma turi:** Responsive Web Application (Mobile & Desktop).

---

## 2. MAQSADLI AUDITORIYA VA FOYDALANUVCHI ROoutputLLAR (USER PERSONAS)

1. **SMM Frilanserlar va Agentliklar:** Bir vaqtning o'zida bir nechta loyihalarni yurituvchi, tezkor g'oyalar va to'liq rejalarga muhtoj mutaxassislar.
2. **Kichik/O'rta Biznes Egalari:** Do'kon, restoran, go'zallik saloni, o'quv markazi kabi biznes egalari (SMM menejeri bo'lmagan holda professional profil yuritmoqchi bo'lganlar).
3. **Ekspertlar va Shaxsiy Brendlar:** O'z xizmatlarini (shifokor, dasturchi, huquqshunos, repetitor) Instagram orqali sotmoqchi bo'lgan shaxslar.

## 3. ASOSIY FUNKSIONAL TALABLAR (CORE MODULES)

### 3.1. Foydalanuvchi va Brend Profili (Brand Onboarding)
Platforma generatsiya qilishdan oldin biznes/brend haqida aniq parametrlarni oladi:
- **Soha / Niche tanlash:** Restoran/Kafexona, Kiyim do'koni, Ta'lim/Kurslar, Go'zallik/Saloni, IT/Texnologiya, Tibbiyot, Ko'chmas mulk, Shaxsiy brend va boshqalar (erkin yozish imkoniyati bilan).
- **Maqsadli Auditoriya (Target Audience):** Yosh, jins, qiziqishlar, asosiy og'riqli nuqtalar (pain points).
- **Muloqot Ohangi (Tone of Voice):** 
  - Do'stona va samimiy
  - Ekspert va professional
  - Qat'iy va savdoga yo'naltirilgan (Hard sell / Soft sell)
  - Hissiyotli / Ilhomlantiruvchi
  - Hazil / Sarcastic / Trendbop
- **Haftalik Asosiy Maqsad (Goal):** 
  - Yangi obunachi jalb qilish (Viral reach)
  - Sotuvlarni oshirish (Direct sales)
  - Auditoriya ishonchini mustahkamlash (Authority & Trust)
  - Yangi mahsulot/xizmat taqdimoti (Launch)

---

### 3.2. 7 Kunlik Kontent Reja Generatori (7-Day Content Plan Engine)
Tizim foydalanuvchi ma'lumotlari asosida 7 kunlik balanslangan kontent matritsasini tuzib beradi:

**Har bir kunlik post kartochkasida quyidagilar bo'ladi:**
1. **Kun va Kontent Turi:**
   - Dushanba: Reels (Ekspert maslahati / Muammo yechimi)
   - Seshanba: Karusel (Foydali qo'llanma / Step-by-step)
   - Chorshanba: Yagona rasm / Infografika (Statistika / Case study)
   - Payshanba: Interaktiv Stories seriyasi + Savol-javob
   - Juma: Sotuv posti (Chegirma / Maxsus taklif / Mahsulot sharhi)
   - Shanba: Mijoz fikri (Social proof / Feedback)
   - Yakshanba: Ko'ngilochar / Shaxsiy hayot / Humor
2. **Post Sarlavhasi / Ilmoq (Hook):** Birinchi 3 soniyada yoki lentada e'tiborni tortuvchi 3 xil variantdagi Hook.
3. **To'liq Post Matni (Caption / Kopirayting):** 
   - AIDA (Attention, Interest, Desire, Action) yoki PAS (Problem, Agitate, Solve) formulalarida yozilgan professional matn.
4. **Harakatga Chaqiruv (CTA - Call To Action):** Izohga kalit so'z yozish ("DIREKT", "NARX"), bio-dagi linkka o'tish yoki saqlab olish.
5. **Vizual Ko'rsatma (Visual Concept / AI Image Prompt):** 
   - Dizayner yoki fotosessiya uchun g'oya tavsifi.
   - Midjourney / DALL-E uchun tayyor inglizcha prompt.
6. **Hashtaglar Strategiyasi:** 
   - 3 ta Katta hajm (Broad)
   - 5 ta Tor sohaviy (Niche)
   - 2 ta Geografik / Mahalliy (Local: #toshkent #uzbekistan)
7. **Tavsiya etiladigan yuklash vaqti:** (Masalan: 13:00 - 14:30 yoki 19:30 - 21:00).

---

### 3.3. Kreativ G'oyalar Laboratoriyasi (Creative Idea Lab)
Foydalanuvchi nafaqat 7 kunlik reja, balki alohida kreativ g'oyalarni ham generatsiya qila oladi:
- **Viral Reels / TikTok Ssenariylari:**
  - Kadrlar bo'yicha ketma-ketlik (Timeline: 0-3s Hook, 3-15s Body, 15-20s CTA).
  - Harakatlar, matnli subtitrlar va tavsiya etiladigan musiqa/ovoz turi.
- **Stories Bo'yicha Voronka (Story Sequence):**
  - 5 ta bog'langan Stories ketma-ketligi (O'yin, so'rovnoma, og'riq, yechim, sotuv).
- **Mavsumiy va Bayram Marketing G'oyalari:**
  - Bayramlar (Navro'z, Hayit, Yangi yil, Black Friday va h.k.) uchun aksiyalar va flesh-mob g'oyalari.
- **AI Hook Generator:**
  - 1 ta mavzu kiritilganda 10 xil qiziqarli sarlavha (Clickbait, Qiziqish uyg'otuvchi, Qarama-qarshi fikr).
- **Post Matnini Yaxshilovchi (Text Rewriter / Optimizer):**
  - Foydalanuvchining xomaki matnini olib, grammatikasini to'g'irlash, emojilar qo'shish va sotuvchan ko'rinishga keltirish.

---

### 3.4. Kontent Taqvim va Boshqaruv (Interactive Calendar & Management)
- **Taqvim ko'rinishi (Calendar / Kanban Board):** Haftalik va oylik taqvimda postlarni sudrab joylashtirish (Drag-and-Drop).
- **Tahrirlash:** Generatsiya qilingan har bir postni platformaning o'zida tahrirlash, matnini o'zgartirish.
- **AI bilan qayta generatsiya:** Faqat bitta kunlik post yoqmasa, alohida "Regenerate only this day" tugmasi.
- **Eksport imkoniyatlari:**
  - 1 bosishda matnni nusxalash (Copy with formatting)
  - PDF hisobot yuklab olish (Mijozga taqdim etish uchun chiroyli dizaynda)
  - Notion / Excel (CSV) formatlarida eksport qilish.

---

### 3.5. Foydalanuvchi Tizimi va To'lovlar (Auth & Monetization)
- **Autentifikatsiya:** Google Sign-In, Telegram orqali kirish, Email/Password.
- **Tarif Rejalari (Freemium):**
  - **Free / Sinov:** 1 ta 7 kunlik reja, 3 ta Reels ssenariysi (bepul).
  - **Pro Plan (Oylik/Yillik):** Cheksiz 7 kunlik rejalar, cheksiz Reels/Stories g'oyalari, PDF eksport.
  - **Agency Plan:** Bir nechta brend profillarini saqlash, jamoaviy ishlash.
- **To'lov tizimlari integratsiyasi:**
  - O'zbekiston uchun: Payme, Click, Uzum Bank.
  - Xalqaro mijozlar uchun: Stripe / Paddle.

## 5. MA'LUMOTLAR BAZASI STRUKTURASI (DATABASE SCHEMA DRAFT)

```dbml
Table users {
  id uuid [pk]
  email string
  full_name string
  created_at timestamp
  subscription_tier string // 'free', 'pro', 'agency'
  tokens_remaining int
}

Table brand_profiles {
  id uuid [pk]
  user_id uuid [ref: > users.id]
  brand_name string
  niche string
  target_audience string
  tone_of_voice string
  instagram_username string
  created_at timestamp
}

Table content_plans {
  id uuid [pk]
  brand_profile_id uuid [ref: > brand_profiles.id]
  user_id uuid [ref: > users.id]
  title string
  week_start_date date
  goal string
  created_at timestamp
}

Table posts {
  id uuid [pk]
  content_plan_id uuid [ref: > content_plans.id]
  day_of_week int // 1 to 7
  content_type string // 'reels', 'carousel', 'single_image', 'stories'
  hooks text[]
  selected_hook text
  caption text
  call_to_action text
  visual_prompt text
  hashtags string[]
  recommended_time string
  status string // 'draft', 'ready', 'published'
}

Table creative_ideas {
  id uuid [pk]
  user_id uuid [ref: > users.id]
  category string // 'viral_reels', 'story_game', 'hook_ideas'
  prompt_input text
  generated_output jsonb
  created_at timestamp
}
```

## 6. PROMPT INJINIRING VA AI STRATEGIYASI

AI barqaror va sifatli javob qaytarishi uchun **JSON Schema** orqali `Structured Outputs` dan foydalaniladi:
- AI ga aniq SMM mutaxassisi roli beriladi (`System Prompt`).
- Chiqish ma'lumotlari qat'iy JSON formatida olinadi (Frontendda parsing xatolari bo'lmasligi uchun).
- O'zbek tili uchun mahalliy madaniyat, mentalitet va so'zlashuv ohangi (masalan, Toshkent yoki butun O'zbekiston auditoriyasiga mos) hisobga olinadi.

## 7. LOYIHANI AMALGA OSHIRISH BOSQICHLARI (ROADMAP)

- **1-Bosqich: MVP (Minimum Viable Product)**
  - UI/UX dizayn va asosiy formalar (Niche, Tone, Goal tanlash)
  - AI bilan bog'lanish va 7 kunlik reja generatsiyasi
  - 1-bosqich natijalarini ko'rish va nusxalash (Copy to clipboard)

  - Autentifikatsiya va shaxsiy kabinet
  - Interaktiv kalendar ko'rinishi
  - PDF eksport qilish funksiyasi

- **3-Bosqich: Kengaytirilgan Kreativ Modul**
  - Viral Reels ssenariy generatori
  - Stories voronkasi generatori
  - AI Image Generator (Midjourney / Stable Diffusion integratsiyasi)
- **4-Bosqich: Avtomatlashtirish (Kelajakda)**
  - Meta/Instagram Graph API integratsiyasi orqali postlarni to'g'ridan-to'g'ri rejalashtirish va yuklash.
